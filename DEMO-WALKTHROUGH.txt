DEMO WALKTHROUGH

Use Chrome. Start with the data from database_setup.sql already loaded.
The sample accounts use DemoPass123! for the password.
This guide uses the normal port 8081. Automated verification used 18081.

1. Show the terminal in the folder with pom.xml.
   Run mvn test and mvn package.
   Say: "This builds our Spring Boot application and runs the unit tests."

2. Show Docker and the database connection.
   Run docker ps, then:
   docker exec -it mysql-server-x370 mysql -u root -p
   USE csx370_mb_platform;
   SHOW TABLES;
   For each table, run SHOW CREATE TABLE table_name\G
   Show SELECT * FROM each table to demonstrate the populated data.
   Say: "The database has nine tables. Primary keys identify rows, foreign
   keys connect them, and pair keys prevent duplicate relationships."
   Use database_setup.sql alongside MySQL to explain data types and checks.

3. Start the app:
   mvn spring-boot:run --% -Dspring-boot.run.arguments="--server.port=8081"
   Open http://localhost:8081/ in Chrome and log in as alex.
   Say: "The home feed includes my own posts and posts from people I follow."

4. Make a post: Working with @maya on our next quiz! #database #study
   Try a blank post and explain that the server rejects it.
   Say: "A new post saves its author, date, hashtags, and mention alerts."

5. Open Profile, then click Maya's name on a post.
   Say: "Profile shows my posts. Clicking another user's name shows only
   that person's posts. Both lists are newest first."

6. Open People. Show @usernames, follow buttons and Sam's Unknown date.
   Follow Jordan, return Home and show Jordan's posts. Unfollow Jordan.
   Say: "Follow relationships are directional. The last active date comes
   only from that person's latest post."

7. Like a post, open its comment icon, and add a comment.
   Show the changed counts, date, and oldest-first comment order.
   Say: "Likes are counted once per user. A user can leave several comments."

8. Bookmark a post and open Bookmarks. Remove the bookmark.
   Say: "Bookmarks belong to the logged-in user. They are sorted by post date."

9. Search #2025 #fireworks, then #database #study.
   Say: "Every requested hashtag must appear in a result. A partial match is
   excluded, and searches ignore letter case."

10. Log in as maya. Open Notifications and find the new mention.
    Show the actor link, post link, activity filter, unread-only filter,
    Mark as read and Mark all as read.
    Say: "Notifications are our additional feature. A follow, like, comment
    or mention creates an alert. Each user can read only their own alerts."

11. Register a new account and show its empty profile. Log out.
    Say: "New accounts can log in and start using the same features."

12. Briefly show er-diagram.png, Readme.txt and dml.sql.
    Say: "Our ER model uses underlined keys, arrows and total-participation
    lines. The SQL file documents what each page reads or changes."

After recording, export every table's final rows if you changed the data.
